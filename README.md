# qihaze123

Building small browser-only tools for SaaS launch workflows.

## Current Project

**BillingWebhookKit** is a browser-only payment webhook test generator for Lemon Squeezy fixtures, HMAC signatures, idempotency keys, contract tests, and duplicate replay checks.

- Live tool: https://qihaze123.github.io/billing-webhook-kit/
- Free sample release: https://github.com/qihaze123/billing-webhook-kit/releases/tag/v0.1.0
- Webhook test checklist: https://gist.github.com/qihaze123/3a13c5533c0e4fe69a3b0759668e9789
- Repository: https://github.com/qihaze123/billing-webhook-kit

The hosted tool has no backend and does not upload webhook signing secrets.
